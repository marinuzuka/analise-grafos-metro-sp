# Grafos para Gephi

Esta pasta contém os arquivos no formato **GEXF** correspondentes aos grafos da rede metroferroviária de São Paulo construídos para os períodos de 1974, 1979 e 1996.

Os grafos foram inicialmente modelados em **Python**, utilizando a biblioteca **NetworkX**, e posteriormente exportados para o formato GEXF para visualização e análise no **Gephi**.

## Arquivos

| Arquivo | Período |
|---|---|
| `grafo_1974.gexf` | 1974 |
| `grafo_1979.gexf` | 1979 |
| `grafo_1996.gexf` | 1996 |

Os arquivos podem ser importados no Gephi para explorar visualmente a estrutura das redes e suas propriedades.
